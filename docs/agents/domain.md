# Documentation du domaine

Le projet possède un seul contexte métier : l’apprentissage des échecs hors ligne.
Les blocs business et front sont des responsabilités techniques, pas des contextes
métier distincts.

Le vocabulaire partagé vit dans `GLOSSARY.md` et les décisions durables dans `docs/adr/` lorsqu'elles existent. Pour les maintenir, utiliser `domain-modeling` selon CU Workflow. Les technologies sont définies dans [les choix technologiques](../architecture-techno.md).
